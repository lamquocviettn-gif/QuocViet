# Website Giới Thiệu Bản Thân - Nguyễn Văn A

Website tĩnh giới thiệu bản thân, xây dựng bằng HTML5 và CSS3, triển khai bằng GitHub Pages.

## Cấu trúc thư mục

```
project/
├── index.html        # Trang chủ
├── about.html         # Giới thiệu bản thân
├── projects.html      # Dự án & kỹ năng
├── contact.html        # Liên hệ
├── css/
│   └── style.css
├── js/
│   └── main.js         # Xử lý menu responsive trên di động
├── images/              # Thư mục chứa ảnh cục bộ (nếu có)
└── README.md
```

## Công nghệ sử dụng

- HTML5
- CSS3 (Flexbox, Grid, Media Queries - responsive cho máy tính và di động)
- JavaScript thuần (chỉ để bật/tắt menu trên di động)

## Ghi chú về hình ảnh

Các ảnh minh họa trong trang hiện đang trỏ tới nguồn Unsplash (https://unsplash.com) qua
đường dẫn trực tiếp, dùng cho mục đích minh họa/bài tập. Nếu nộp bài, bạn nên:
1. Thay bằng ảnh cá nhân thật của bạn, hoặc
2. Tải ảnh về và lưu vào thư mục `images/`, sau đó sửa lại đường dẫn `src` trong các file
   HTML thành đường dẫn tương đối, ví dụ: `images/avatar.jpg`.
3. Ghi rõ nguồn ảnh nếu sử dụng ảnh từ bên ngoài (theo đúng yêu cầu đề bài).

## Cách chạy thử trên máy

Chỉ cần mở file `index.html` bằng trình duyệt (Chrome, Edge, Firefox...).

## Cách triển khai lên GitHub Pages

1. Tạo repository mới trên GitHub (ví dụ: `my-profile-website`).
2. Đưa toàn bộ nội dung thư mục này lên repository đó.
3. Vào repository trên GitHub → **Settings** → mục **Pages**.
4. Ở phần **Source**, chọn nhánh `main` (hoặc `master`) và thư mục `/ (root)`, sau đó bấm **Save**.
5. Đợi khoảng 1-2 phút, GitHub sẽ cung cấp đường dẫn dạng:
   `https://<tên-tài-khoản>.github.io/<tên-repo>/`
6. Mở đường dẫn đó để kiểm tra website đã hoạt động đúng (không lỗi liên kết, không lỗi ảnh).
